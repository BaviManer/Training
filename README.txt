Цикл-28 как приложение на телефоне

1. Выложите всю папку на любой HTTPS-хостинг. Подойдёт GitHub Pages, Netlify (перетащить папку на netlify.com/drop), Cloudflare Pages или свой сервер.
2. Откройте адрес на телефоне.
   iPhone (Safari): «Поделиться» -> «На экран Домой».
   Android (Chrome): меню -> «Установить приложение».
3. После первого открытия приложение работает без интернета. Прогресс хранится на устройстве.

Если открыть index.html просто как файл, всё работает так же, но установить его как приложение нельзя: для этого нужен HTTPS-адрес.
Перенос прогресса между устройствами: вкладка «Инструменты» -> «Резервная копия».
